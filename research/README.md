# Research material

Preserved prototypes, probes and captures. Nothing here is needed to install mods.

| Folder | What it is |
| :--- | :--- |
| [`legacy/`](legacy/README.md) | Early high-level emulator prototypes (`python -m research.legacy.<prototype>`); not fidelity tests |
| [`probes/`](probes/README.md) | Freestanding ARMv7 read-only probes and their build/receipt harness |
| `reports/` | Hardware telemetry captures cited by code and evidence (`a6400_hw_dump.txt`) |
| [`reference/`](reference/README.md) | Local reference assets for the legacy renderer |

Dated findings live in [`docs/evidence/`](../docs/evidence/README.md); the
[knowledge map](../docs/map/README.md) is the index.
